# Agent Kernel v0.1.0 Release Notes

Status:

```text
Release candidate documentation for v0.1.0
```

Agent Kernel v0.1.0 is the first end-to-end runtime foundation release.

It is not a toy demo. It includes a modular runtime, API, CLI, worker, RAG,
memory, tools, approvals, observability, deterministic evals, Web Workbench,
Docker Compose stack definition, documentation, and examples.

## Highlights

- Core agent run lifecycle.
- FastAPI API.
- Typer CLI.
- Background worker.
- LLM provider abstraction.
- Mock, replay, and OpenAI provider baseline.
- Model routing.
- Prompt versioning foundation.
- Tool interface, registry, schema validation, and executor.
- Tool risk levels and policy decisions.
- Human approval records.
- Approval interrupt/resume.
- Retry and fallback policy.
- RAG knowledge base, document upload, ingestion, chunking, indexing, retrieval,
  citations, and `kb_search` tool.
- Scoped memory CRUD, retrieval, and model context injection.
- Trace IDs, structured logs, runtime metrics, and retrieval metrics.
- Deterministic RAG eval datasets and CLI reports.
- Next.js Agent Workbench.
- Playwright smoke tests.
- Docker Compose local stack definition.
- Release-facing docs and examples.

## User-Facing Shape

Backend runtime:

```text
create agent -> create run -> queue run -> worker executes -> inspect output and timeline
```

RAG workflow:

```text
create KB -> upload document -> ingest -> chunk -> index -> retrieve -> kb_search
```

Memory workflow:

```text
create memory -> list/inspect/delete -> explicit scoped retrieval -> model context injection
```

Eval workflow:

```text
JSON eval dataset -> deterministic runner -> CLI JSON report -> CI cheap eval
```

Workbench workflow:

```text
Dashboard -> Agents -> Runs -> Approvals -> Knowledge -> Evals -> Settings
```

## Known Limitations

Important v0.1 limitations:

- Web Workbench is mostly fixture-backed.
- Web approval decisions are local UI state only.
- Auth, RBAC, browser sessions, and tenant isolation are not implemented.
- Provider-native function calling is not implemented.
- Automatic model planning for tool choice is not implemented.
- Durable provider-returned tool-call loop is not implemented.
- Redis-backed distributed queue and worker leases are not implemented.
- OpenAI embeddings are not implemented.
- pgvector-native vector indexes are not implemented.
- Retrieval is vector-only with deterministic mock embeddings by default.
- Hybrid search, BM25, RRF, reranking, and query rewriting are not implemented.
- Semantic memory retrieval and automatic memory writes are not implemented.
- OpenTelemetry exporters and Prometheus endpoint are not implemented.
- Eval runs are not persisted and eval API endpoints are not implemented.
- S3/MinIO object storage backend is not implemented.
- Full public multi-tenant production security is not implemented.
