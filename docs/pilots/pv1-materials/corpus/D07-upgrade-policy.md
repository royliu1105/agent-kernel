# D07: upgrade-policy

本地脱敏摘要草案；待人工审核，未授权外发或导入知识库。
仅描述版本化文档约定，不证明当前 Docker 已部署该版本。

## D07-S1: 升级写入边界

升级前停止 API 写入和所有 Worker，建立并验证备份，确认迁移兼容性，再执行明确的迁移任务并部署对应应用。API 也执行审批续跑，不能只停止队列 Worker。不能混用缺少 fencing/checkpoint 保护的旧执行器与新执行器。

## D07-S2: 旧检查点

旧 native 审批缺少 checkpoint 时拒绝续跑，不猜测历史。旧 SYSTEM-memory checkpoint 不自动转换；应先核对已发生效果，再决定是否创建经审核的新 Run。不能修改 checkpoint 版本以绕过验证；降级会丢失续跑历史，存在待审批任务时不得盲目降级。

## D07-S3: 回滚

只有确认旧应用与当前数据库兼容时才考虑仅回滚应用。破坏性或不兼容变更优先使用已验证的备份恢复，不把 Alembic downgrade 当作生产备份替代品。兼容性明确之前保持 Worker 停止。
