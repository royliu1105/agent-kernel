# D06: backup-restore

本地脱敏摘要草案；待人工审核，未授权外发或导入知识库。
仅描述版本化文档约定，不证明当前 Docker 已部署该版本。

## D06-S1: 备份单元

PostgreSQL 与匹配的对象存储备份必须作为协调单元；还需记录不含明文秘密的部署配置、秘密恢复流程、应用版本、git SHA、镜像 digest、Alembic revision 和备份时间。仅有数据库备份不足以保证文档对象可恢复。

## D06-S2: 协调与恢复

备份前停止 Worker，并控制 API 写入；需要严格一致性时使用合适快照或维护窗口。先在隔离环境恢复数据库及同一备份点的对象，核对配置与迁移，验证健康、记录及对象一致性，再考虑提升为服务环境。

## D06-S3: 目标与安全

RTO 是可接受恢复时间，RPO 是可接受数据丢失窗口，二者由运维方案决定，系统不自动保证。备份可能包含输入、工具参数结果、审批、记忆和文档，必须加密、限权，并与运行凭据分离管理恢复凭据。
