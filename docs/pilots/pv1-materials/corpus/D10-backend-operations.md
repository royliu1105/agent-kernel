# D10: backend-operations

本地脱敏摘要草案；待人工审核，未授权外发或导入知识库。
仅描述版本化文档约定，不证明当前 Docker 已部署该版本。

## D10-S1: 权威状态与队列

PostgreSQL 保存 Run、审批、事件和所有权，是权威状态；Redis 列表只是调度提示。先提交 queued Run，再尝试 enqueue。提示丢失、重复或 Redis 故障不会删除已提交任务，Worker 每轮仍轮询数据库。LPOP 不是完成确认，也不是执行锁。

## D10-S2: 不要混淆故障策略

Redis 调度提示不可用时可继续从数据库发现已排队任务；但启用共享准入限流后，限流所需 Redis 不可用返回 503，不能悄悄放行。超额请求返回 429 与 Retry-After。

## D10-S3: 进程重启不是任务重试

Docker 可监督 Worker 重启；运行中不确定任务仍需租约过期和显式恢复，不因为进程重启就重复执行。限流计数也不是持久化账单或硬费用上限。
