# D12: bounded-execution

本地脱敏摘要草案；待人工审核，未授权外发或导入知识库。
仅描述版本化文档约定，不证明当前 Docker 已部署该版本。

## D12-S1: 有界执行

模型到工具再到模型循环受可信服务端配置约束：模型尝试次数、工具次数、活动时间、历史字节、观察到的 token/cost，以及每次输出 token 上限。用户输入不能提高限制。审批等待不算活动时间，计数跨审批保留，新执行器可收紧但不能扩大已存预算。本文不声称试点提议值已经生效。

## D12-S2: 续跑与策略

一个响应内工具按顺序串行执行；存在 native 历史后固定 provider/model，不跨 provider fallback。所有工具经过 schema 和当前策略检查；对已拒绝审批进行 resume 时终止 Run，不调用其工具或模型，审批决策本身不执行续跑。未知、重复、不一致 call ID 在副作用前拒绝。

## D12-S3: 退避与费用边界

只有合格的瞬时错误重试，指数退避加抖动并尊重有效 Retry-After；超过等待预算则失败，不提前请求。等待可取消且保留 heartbeat。永久错误、被拒绝工具、写工具和审批保护工具不因此获得自动重试。观察到的预算与取消操作不能保证阻止在途请求扣费。
