# D05: external-tools

本地脱敏摘要草案；待人工审核，未授权外发或导入知识库。
仅描述版本化文档约定，不证明当前 Docker 已部署该版本。

## D05-S1: 可信工具约定

工具风险、read_only、idempotent、retry_safe、policy_decision 和超时由本地运维配置决定，远端描述或模型输出不能授予这些权限。read_only=true 不会自动免审批；显式策略按 deny、require_approval、allow 从严组合。每次调用仍要通过工作区、参数和超时检查。

## D05-S2: 网络与重试

工作区 allowlist 默认空；授权上下文来自持久化 Run。OpenAPI 只暴露显式绑定的操作，端点由受信任配置固定，不采用规范中的服务器地址。私网访问必须明确允许，不能借此访问用户指定的任意地址。写操作不自动重试；远端是否去重需要独立验证。

## D05-S3: 证据

一次成功的 fixture 调用不是故障情况下 exactly-once 的保证。应结合持久化工具记录和下游独立调用日志判断效果；本材料没有配置或授权真实业务工具目标。
